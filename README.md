# pi-router-extension

Автоматическое обновление моделей OpenAI-совместимых API и необязательный прогресс генерации в [pi](https://github.com/earendil-works/pi).

Нет встроенного адреса сервера или обязательного имени провайдера. Каталог загружается по `baseUrl + /models` для настроенных подключений. Прогресс и баланс включаются только при заголовке ответа `X-Router-Events: v1`; без этого обычный API работает как прежде.

## Установка Linux

```bash
curl -fsSL https://raw.githubusercontent.com/slavamirniy/pi-router-extension/main/installer/install-pi-linux.sh | env PI_API_KEY='KEY' PI_BASE_URL='https://YOUR_API/v1' bash
```

## Установка Windows

Обычная командная строка CMD автоматически запустит встроенный PowerShell:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/slavamirniy/pi-router-extension/v1.0.4/i.ps1|iex; Install-Pi 'KEY' 'https://YOUR_API/v1' 'kimi-k3'"
```

Замените ключ и адрес API. Команда работает в CMD и PowerShell. Бот подставляет значения автоматически; редкие значения со специальными символами оболочки передаёт через безопасную кодированную форму. Команда содержит ключ: не пересылайте её другим людям.

Для PowerShell также доступна короткая форма:

```powershell
$env:PI_API_KEY='KEY'; $env:PI_BASE_URL='https://YOUR_API/v1'; irm https://raw.githubusercontent.com/slavamirniy/pi-router-extension/main/installer/install-pi-windows.ps1 | iex
```

Установщики ставят Node.js при необходимости, проверенную версию pi **0.84.4**, расширение и конфигурацию API. Плагин скачивается из закреплённого коммита; SHA-256 каждого файла проверяется до запуска. Установщики не отправляют API-ключ на GitHub и не передают его npm. Ключ сохраняется в личном `~/.pi/agent/models.json` для дальнейшей работы pi; файлы Unix имеют права 600. Предыдущие настройки сохраняются в резервные копии. Остальные провайдеры и настройки сохраняются.

`PI_BASE_URL` обязателен и включает API-путь, например `/v1`. `PI_PROVIDER_NAME` — необязательное имя подключения (по умолчанию `router`); `PI_DEFAULT_MODEL` — необязательный ID из полученного каталога. `PI_CODING_AGENT_DIR` позволяет указать другую папку pi. Если имя подключения уже занято другим URL, установщик попросит выбрать новое имя.

После установки pi запускается автоматически. `PI_NO_START=1` отключает запуск; `PI_SKIP_INSTALL=1` позволяет только обновить расширение и настройки, когда поддерживаемый pi уже установлен. В текущем pi используйте `/reload`.

Для установки только плагина в существующий pi:

```bash
pi install git:github.com/slavamirniy/pi-router-extension
```

## Поведение

- При запуске обновляются модели каждого настроенного API; `/models-refresh` обновляет вручную. Подключение может первоначально иметь `models: []`.
- Каждый успешно полученный полный каталог заменяет прежний список моделей этого подключения, включая пустой каталог. Специальные заголовки API не нужны. Другие подключения сохраняются.
- Актуальный список сохраняется в `models.json`, прежняя версия — в `models.json.previous`. Ключи и прочие настройки сохраняются. Изменения подключения во время загрузки не перезаписываются. Если выбранная модель удалена, в простаивающей сессии выбирается первая доступная модель того же провайдера.
- Если загрузка не удалась, прежний список остаётся. Опрос ограничен таймаутом, размером ответа и четырьмя параллельными запросами. Неполные каталоги не удаляют модели.
- Контекст и выход берутся из метаданных API. Для GLM-5.3 без метаданных есть профиль 1M/128K; явно меньшие ограничения API имеют приоритет.
- Прогресс: одна строка с состоянием, временем, последними 50 символами и расходом квоты. Баланс внизу: `Осталось 998 млн` или `Осталось 250 тыс.`.
- Ошибки дополнительных endpoint'ов не отменяют генерацию, не запускают платных повторов и не прерывают lifecycle pi. Главные ошибки генерации отображает pi.
- Превью очищается от управляющих последовательностей, не добавляется в историю и контекст. Для подтверждённого неудачного ответа роутера незавершённые текст и инструменты исключаются из сообщения и контекста.

`/router-progress on|off` управляет видимостью. После установки каталог обновляется при каждом старте и сохраняется в `models.json`; сохранённый файл служит резервом на случай недоступности API.

## Проверка

```bash
npm test
```

Проверены произвольные адреса/имена, обычный API без дополнительных endpoint'ов, отказ сети, сохранение сторонних моделей, пустой авторитетный каталог, прерывание генерации, обновление квоты и изолированная установка. Для полноценного Linux-прогона нужен Linux; Bash-сценарий также проверяется Git Bash на Windows.
